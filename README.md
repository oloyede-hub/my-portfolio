# Sodiq Oloyede — Portfolio

My personal portfolio showcasing my work in **full-stack software engineering, healthcare technology, and artificial intelligence**.

Built to highlight the projects, technologies, and experiences shaping my journey as a software engineer working at the intersection of **software, healthcare, and AI**.

## 🚀 Featured Projects

### UltraLink Live
A real-time tele-ultrasound collaboration platform designed to connect ultrasound operators with remote experts for live guidance, consultation, and case collaboration.

**Tech:** Next.js, TypeScript, NestJS, PostgreSQL, Prisma, LiveKit, WebSockets

### Pneumonia Detection AI
A deep-learning system for automated pneumonia detection from chest radiographs, with **Grad-CAM explainability** for visualizing the image regions influencing model predictions.

**Tech:** Python, TensorFlow, Keras, VGG16, Grad-CAM, FastAPI

### Medivix
An interactive medical visualization project focused on making radiographic equipment, imaging systems, and complex medical imaging concepts easier to understand through interactive visual experiences.

**Tech:** React, TypeScript, Three.js

## 💻 Running Locally

Clone the repository:

```bash
git clone https://github.com/oloyede-hub/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Then open:

```text
http://localhost:3000
```
